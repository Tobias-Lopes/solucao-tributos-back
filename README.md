# solucao-tributos-back

## Propósito

Este projeto fornece uma API backend para gerenciar categorias e vendas, voltada para soluções tributárias. Realiza operações de CRUD com validação e integração ao banco de dados via Prisma.

## Requisitos

- [Docker](https://www.docker.com/)
- [Yarn](https://yarnpkg.com/)

## Como começar

1. **Clone o repositório:**
   ```sh
   git clone <repo-url>
   cd solucao-tributos-back
   ```
2. **Inicie as dependências com Docker Compose:**
   ```sh
   docker-compose up -d
   ```

3. **Instale as dependências:**
   ```sh
   yarn install
   ```

4. **Execute o servidor de desenvolvimento:**
   ```sh
   yarn dev
   ```

## Uso

O backend ficará disponível localmente na porta `http://localhost:3000/api`. Certifique-se de que os containers Docker estejam ativos antes de iniciar o servidor.
